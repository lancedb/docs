<Badge color="red">Enterprise</Badge> [SQL runs in LanceDB Enterprise.](/oss/v0-98-0/sql)

```sql
UPDATE documents SET title = upper(title) WHERE category = 'film'
```

Assignments take any expression the [dialect](/oss/v0-98-0/sql/functions) supports,
including references to other columns of the same row. Without a `WHERE`
clause every row is updated.

<Warning>
An update does not recompute [computed columns](/oss/v0-98-0/feature-engineering/add-computed-column)
that derive from the column you changed. Those rows keep the value computed from
the old input until the next refresh recomputes them -- see
[Guarantees](/oss/v0-98-0/basics/guarantees#jobs).
</Warning>

Commits a new table version, so [versioning](/oss/v0-98-0/management/table#versioning) and
the [write guarantees](/oss/v0-98-0/basics/guarantees#writes) apply -- including that the
version advances even when the statement affects zero rows.
