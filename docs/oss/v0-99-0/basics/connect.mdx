The URI you pass to `connect` decides where the work runs. The same Python,
TypeScript and Rust SDKs open all three kinds;
[OSS and Enterprise](/oss/v0-99-0/basics/offerings) describes how the two offerings differ.

| URI | Where queries run |
| --- | --- |
| A local path, such as `./data` | OSS: in your process |
| `s3://`, `gs://` or `az://` | OSS: in your process, reading object storage |
| `db://` | LanceDB Enterprise: queries run on your cluster |

## A local directory {#local}

Embedded in your application, LanceDB reads and writes the tables in a
directory on disk.

<CodeGroup>
    ```python Python (sync) icon="python"
    import lancedb

    uri = "ex_lancedb"
    db = lancedb.connect(uri)
    ```

    ```python Python (async) icon="python"
    import lancedb

    uri = "ex_lancedb"
    async_db = await lancedb.connect_async(uri)
    ```

    ```typescript TypeScript icon="square-js"
    import * as lancedb from "@lancedb/lancedb";

    const db = await lancedb.connect("ex_lancedb");
    ```

    ```rust Rust icon="rust"
    use lancedb::connect;

    let db = connect("ex_lancedb").execute().await?;
    ```
</CodeGroup>

## Object storage {#object-storage}

With an object storage URI the library is still embedded: your process runs
every query and reads and writes the bucket directly, with the credentials from
its environment or its storage options. [Configuring storage](/oss/v0-99-0/deployment/storage)
covers credentials, endpoints and provider options.

<CodeGroup>
    ```python Python (sync) icon="python"
    import lancedb

    uri = "s3://your-bucket/path"
    # You can also use "gs://your-bucket/path" or "az://your-container/path".
    db = lancedb.connect(uri)
    ```

    ```python Python (async) icon="python"
    import lancedb

    uri = "s3://your-bucket/path"
    # You can also use "gs://your-bucket/path" or "az://your-container/path".
    async_db = await lancedb.connect_async(uri)
    ```

    ```typescript TypeScript icon="square-js"
    import * as lancedb from "@lancedb/lancedb";

    const uri = "s3://your-bucket/path";
    // You can also use "gs://your-bucket/path" or "az://your-container/path".
    const db = await lancedb.connect(uri);
    ```
</CodeGroup>

In Rust, pass the same URI to `connect`.

## LanceDB Enterprise {#enterprise}

A `db://` URI connects to LanceDB Enterprise, where your cluster runs queries
and background work. Get the database URI, API key, region and endpoint from
your administrator, then replace the placeholders below. Use your cluster's region
in place of `us-east-1`. In application code, load credentials from environment
variables or a secrets manager.

<CodeGroup>
    ```python Python icon="python"
    import lancedb

    db = lancedb.connect(
        uri="db://your-database",
        api_key="your-api-key",
        region="us-east-1",
        host_override="https://your-endpoint",
    )
    ```

    ```typescript TypeScript icon="square-js"
    import * as lancedb from "@lancedb/lancedb";

    const db = await lancedb.connect("db://your-database", {
      apiKey: "your-api-key",
      region: "us-east-1",
      hostOverride: "https://your-endpoint",
    });
    ```
</CodeGroup>

In Rust, enable the crate's `remote` feature; the connection builder then takes
the same settings through `api_key`, `region` and `host_override`. To use OAuth
instead of an API key, see
[Authentication](/oss/v0-99-0/enterprise/authentication); for every connection option, see
[Database](/oss/v0-99-0/management/database#deployment).


<Accordion title="Load production credentials from your environment">

Set these values in the shell that starts your application. Replace the URI, API
key, region and endpoint with your Enterprise connection settings. In production, a secrets
manager can supply these environment variables for you.

```shell
export LANCEDB_URI="db://your-database"
export LANCEDB_API_KEY="your-api-key"
export LANCEDB_REGION="us-east-1"
export LANCEDB_HOST_OVERRIDE="https://your-endpoint"
```

<CodeGroup>
  ```python Python icon="python"
  import os

  import lancedb

  db = lancedb.connect(
      uri=os.environ["LANCEDB_URI"],  # db://your-database
      api_key=os.environ["LANCEDB_API_KEY"],
      region=os.environ.get("LANCEDB_REGION", "us-east-1"),
      host_override=os.environ["LANCEDB_HOST_OVERRIDE"],  # https://your-endpoint
  )
  ```
  ```typescript TypeScript icon="square-js"
  import * as lancedb from "@lancedb/lancedb";

  const setting = (name: string) => {
    const value = process.env[name];
    if (!value) throw new Error(`Set ${name}`);
    return value;
  };

  const db = await lancedb.connect(setting("LANCEDB_URI"), {
    apiKey: setting("LANCEDB_API_KEY"),
    region: process.env.LANCEDB_REGION ?? "us-east-1",
    hostOverride: setting("LANCEDB_HOST_OVERRIDE"),
  });
  ```
</CodeGroup>

</Accordion>
