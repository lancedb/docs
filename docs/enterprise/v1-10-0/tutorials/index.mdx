Every tutorial is one page in the sidebar, grouped by what it builds. The
documentation explains how a feature works; these show it doing something.

Examples marked as notebooks live in the
[vectordb-recipes](https://github.com/lancedb/vectordb-recipes) repository and
are runnable in Colab; the rest are written up here.

## The features these use {#read-the-docs}

| Feature | What it covers |
|:--------|:------------|
| [Vector search](/enterprise/v1-10-0/search/vector-search) | Similarity search, distance metrics, and tuning it. |
| [Full-text search](/enterprise/v1-10-0/search/full-text-search) | Keyword search over text columns. |
| [Hybrid search](/enterprise/v1-10-0/search/hybrid-search) | Keyword and vector search combined. |
| [Multi-vector search](/enterprise/v1-10-0/search/vector-search) | Several embeddings per document. |
| [Reranking](/enterprise/v1-10-0/reranking) | Reordering results to improve the top-k. |
| [Feature engineering](/enterprise/v1-10-0/feature-engineering) | Deriving columns and tables from data already stored. |
| [Materialized views](/enterprise/v1-10-0/management/materialized-view) | A table defined by a query, brought up to date by each refresh. |
| [Training](/enterprise/v1-10-0/training/data-loading) | Reading a table into a data loader. |
