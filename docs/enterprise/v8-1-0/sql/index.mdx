LanceDB Enterprise supports SQL through an Arrow Flight SQL endpoint. This
reference covers statement syntax, data types and expressions. To set up a
client and run your first query, see [SQL](/enterprise/v8-1-0/basics/sql).

## The dialect {#dialect}

LanceDB uses [Apache DataFusion](https://datafusion.apache.org) for SQL planning
and execution. These pages describe LanceDB's supported statements and
extensions. DataFusion's reference is useful for expression syntax, but does
not establish that every DataFusion statement or feature is exposed by
LanceDB.

## Connecting {#connecting}

Use Python's `execute_query` or a Flight SQL client after configuring the
[Enterprise connection](/enterprise/v8-1-0/basics/sql#sql-is-remote). TypeScript applications
use a Flight SQL client for SQL queries.

```python
reader = db.execute_query("SELECT id, text FROM my_docs LIMIT 10")
for batch in reader:
    print(batch)
```

SQL results arrive as Arrow record batches. Iterating over the reader avoids
collecting the entire result in application memory. See
[Queries](/enterprise/v8-1-0/basics/query) for result handling.

## Usage {#usage}

The endpoint executes one statement per request and is meant for the queries
and DDL/DML pages below. Reach for the SDKs instead for table-management
operations that have no SQL form, such as a merge insert -- see
[What SQL cannot do](#cannot).

## SQL limitations and alternatives {#cannot}

| | |
| --- | --- |
| Vector search | See [SQL vector search](/enterprise/v8-1-0/basics/sql#no-vector-sql) for supported query forms and server-version requirements. The [SDK query builder](/enterprise/v8-1-0/search/vector-search) also supports vector search. |
| Merge insert | no SQL form -- needs a source relation and a per-match policy |
| `information_schema` | not enabled, so `SHOW TABLES` and `SHOW COLUMNS` fail |
| `COPY` | refused by recent deployment versions -- see [Copy](/enterprise/v8-1-0/sql/dml/copy) |
| `PREPARE` / `EXECUTE` | preparation is a [protocol feature](/enterprise/v8-1-0/sql/prepared-statements), not a statement |
| Run on a local database | no engine to plan the statement |

See [Limits](/enterprise/v8-1-0/basics/limits#sql) for the bounds these pages enforce.
