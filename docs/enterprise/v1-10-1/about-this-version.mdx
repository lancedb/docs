- **Shared pages and examples:** `lancedb/lancedb` commit `19991cea32c696767f1d0124f4959700a926b4e4`, the LanceDB this release bundles
- **Enterprise pages:** the Enterprise documentation of this release

- **REST API specification:** `lance-format/lance-namespace` `v0.12.0`

An Enterprise release bundles a particular LanceDB, which can be older than the newest LanceDB OSS release. The pages it shares with LanceDB OSS can then differ from the newest LanceDB OSS documentation.
