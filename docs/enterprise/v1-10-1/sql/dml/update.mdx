<Badge color="red">Enterprise</Badge> [SQL runs in LanceDB Enterprise.](/enterprise/v1-10-1/sql)

```sql
UPDATE documents SET title = upper(title) WHERE category = 'film'
```

Assignments take any expression the [dialect](/enterprise/v1-10-1/sql/functions) supports,
including references to other columns of the same row. Without a `WHERE`
clause every row is updated.

<Warning>
An update does not recompute [computed columns](/enterprise/v1-10-1/feature-engineering/add-computed-column)
that derive from the column you changed. Those rows keep the value computed from
the old input until the next refresh recomputes them -- see
[Guarantees](/enterprise/v1-10-1/basics/guarantees#jobs).
</Warning>

Commits a new table version, so [versioning](/enterprise/v1-10-1/management/table#versioning) and
the [write guarantees](/enterprise/v1-10-1/basics/guarantees#writes) apply -- including that the
version advances even when the statement affects zero rows.
